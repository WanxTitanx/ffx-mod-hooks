# Public MOD-006 authoring contract

The current public contract is [Separate game-language packs — API 4](../TEXT_LANGUAGE_PACKS.md).
Use its schemas and producer guide with the exact supported executable profile.
The source tree contains tooling and validated metadata; the PT-BR game
translation, proprietary assets and private verification fixtures are not shipped.

The earlier API 1–2 contract remains available in the beta.3 tag/history. These
source changes do not certify live visual fit or authorize redistributing game
resources. Editor integration should keep native game data, native locale IDs,
saves and audio separate from an explicitly selected virtual text pack.
