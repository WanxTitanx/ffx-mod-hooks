## Behavior and identity

- Retains all 78 identities and selected original artworks, including the corrected Nine of Cups revision. The compiled catalog uses typed handlers; free-text design descriptions are never executed.
- `[arcana] enabled=0` and `[development] arcana_full_deck=0` are OFF by default. F8 Reforge enables Arcana for the next process; F8 Development offers the live grant once the native Arcana provider is available. Switching the grant off preserves acquired cards.
- Native Equip retains Weapon/Armor indices 0/1. Tarot selection is private, with two slots in Twin mode or three slots with capacity four in Constellation mode. Major cards weigh two; minors weigh one. Transfers and removal of third slots require explicit in-menu confirmation.
- Uses native menu text, panels, cursor and input callbacks. The card artwork is drawn through the shared D3D11 Present provider with WIC decoding and three cached textures. Missing graphics support preserves a native text fallback.
- The first card is The Fool. Temple and sidequest rewards reconcile from native progress; named challenges grant Devil, Tower, Sun and Judgement. World requires the other 77 cards. See the [complete rules](../../research/mod_008_arcana/acquisition-v1.md).
- Unique acquisition/ownership lives in a bounded 276-byte extension tied to native-save SHA-256 and the compiled catalog identity. Save-as carries the current collection. Foreign/corrupt extensions fail closed without replacing a valid recovery copy.

The combat seam preserves registers, flags and x87/SSE state, then resumes native cap/Trio logic. Half MP uses the native ceiling division once; remaining percentage reductions form one additional layer. One MP and Spellspring remain native. Actual HP deltas, action tokens and turn edges govern healing, kill rewards and temporary statuses. A subsequent native status source takes ownership so the card timer cannot remove that source's effect.

Workshop supplies the shared native field/aggregate/damage/load scopes when active. Otherwise Arcana installs those producers once. Save notifications support bounded independent subscribers; serialization projects a copied buffer, seals its checksum, prepares the extension, executes one native write, then commits or aborts the journal. A metadata preparation failure still writes the projected native save and reports the extension failure. Temporary maxima/flags are removed from the native copy; the extension retains enlarged current resources for an ON reload.

## Teardown review

All new hooks default OFF. Entered trampolines and callback storage have process lifetime; logical stop closes admission. `DllMain` stop paths use atomics, nonblocking observer removal, a best-effort preview hide and a kernel wake event. They perform no install, file I/O, join, sleep or drain. Graphics COM references are released on the owning render thread; context state is swapped back after drawing and the private context is cleared so it cannot retain a resize-sensitive backbuffer. The WIC worker is not joined under loader lock.

If temporary field values remain after logical stop, native save projection and its required IAT producer remain admitted until those values are recalculated by the game. Observer cookies already in a write transaction finish after unsubscribe. Save-generation changes reject old UI commands and keep image requests from the previous actor/menu from replacing current requests.

## Limits and next gate

- Native visual fit, real controller timing, all 78 cards in gameplay, encounter pacing and end-to-end rewards need the separately authorized RT2 protocol. WARP proves image decode/draw/state restoration, not the native menu's visual appearance.
- Additional white/item healing, MP percentages, CTB and reactive effects are battle consumers. Full parity with the field Skills/Items menu is not established. Native field maxima/stats and the native flags are separately projected/tested.
- A failed primary CRT write remains a failed native write. No rollback is claimed for an underlying partial/truncated native file. Sidecar recovery requires a matching complete native image; file identity or projection rejection is reported instead of inventing ownership.
- This is author verification, not independent review. After the absence of an independent reviewer was disclosed, the user explicitly requested commit, branch synchronization, PR and merge. That later instruction selects integration after the GitHub checks; it does not authorize subagents or promote the candidate to RT2/Production. No independent review is claimed.
