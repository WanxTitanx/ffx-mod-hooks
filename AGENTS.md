# Public Hooks release notes

This repository is the public FFX Hooks source/release mirror. Follow
`docs/PATCH_NOTES.md` for public patch notes and website handoffs.

- Every completed note contains full, equivalent English and Brazilian Portuguese.
  The website coordinator handles the other seven languages.
- Reuse the same pair in the release-note file, `CHANGELOG.md` and the GitHub
  Release body. Website category: `hooks`; preserve the exact version and stage.
- Explain player-visible changes, prerequisites and known limits. Keep technical
  evidence separate; never turn a successful build into a claim of gameplay proof.
- Preserve the public editorial contract when refreshing this mirror from its
  development source. Do not import private handoffs, credentials or research dumps.
- These instructions authorize no publication, binary deployment, game execution,
  credential change or release-gate bypass. Respect existing work and permissions.
