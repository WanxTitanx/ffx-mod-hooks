# ffx-hooks-releases

Official release face for **ffx-hooks** — the runtime engine hook layer for
FINAL FANTASY X/X-2 HD Remaster (Steam, PC).

## Status: BETA

This project just left alpha. Expect bugs and mod incompatibilities.
Use a disposable save. All hooks are OFF by default.

## Downloads

Grab the latest release from the [Releases page](https://github.com/WanxTitanx/ffx-hooks-releases/releases).

## What works

- **F7 In-Live menu**: difficulty levers (RAM-only), Force Last Battle,
  music control, Monster AI Swap.

## Roadmap

- F8 Dashboard (implemented, disabled — next release candidate)
- ffx-probe Tier 2 (main-thread probe return)
- Safe UnX-style ports (dialog skip, cheats, boosters)
- FFX Mod Studio integration

Source code lives in a private repo during beta. It will be published when
