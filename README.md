# FFX Mod Hooks

## English

Public distribution repository for FFX Mod Hooks. Download DLLs and installation packages from [Releases](https://github.com/WanxTitanx/ffx-mod-hooks/releases). Release notes, version numbers, beta status and package requirements remain attached to each version.

The project is now developed privately. This repository contains no project source code. GitHub-generated “Source code” archives contain only distribution documentation. Historical source packages are no longer offered here; references to source in older notes or manifests describe the original publication. Existing packages retain their included license and third-party notices.

## Português (Brasil)

Repositório público de distribuição do FFX Mod Hooks. Baixe as DLLs e os pacotes de instalação em [Releases](https://github.com/WanxTitanx/ffx-mod-hooks/releases). As notas, os números de versão, o estágio beta e os requisitos dos pacotes continuam associados a cada versão.

O projeto passa a ser desenvolvido de forma privada. Este repositório não contém o código-fonte do projeto. Os arquivos “Source code” gerados pelo GitHub contêm apenas a documentação de distribuição. Os pacotes históricos de código-fonte não são mais oferecidos aqui; as referências ao código em notas ou manifestos antigos descrevem a publicação original. Os pacotes existentes mantêm suas licenças e os avisos de terceiros incluídos.
